## 基础知识

### Python 的变量只是“指向对象的引用”

其他语言（如 C、Java 基本类型）中变量是一个“盒子”，赋值是把值放进盒子。
Python 不同：**变量只是绑定到对象上的一个名字（标签）**，赋值语句 `a = b` 从不拷贝数据，只是让 `a` 也指向 `b` 所指向的那个对象。

```python
a = [1, 2, 3]
b = a          # 不是复制列表，而是让 b 指向同一个列表对象
b.append(4)
print(a)       # [1, 2, 3, 4]  ← a 也“变”了，因为它们是同一个对象
print(a is b)  # True，is 判断是否为同一个对象（id 相同）
```

可以用 `id()` 查看对象的身份（内存地址近似值）：

```python
a = 10
print(id(a))   # 例如 140711856470120
b = a
print(id(b))   # 与 id(a) 相同 —— 两个名字指向同一个对象
```

### 一切皆对象：变量没有类型，对象才有类型

类型信息挂在**对象**上，而不是变量上。变量随时可以重新绑定到任何类型的对象：

```python
x = 10        # x 指向 int 对象
x = "hello"   # x 现在指向 str 对象，x 本身“没有类型”
```

### 可变对象与不可变对象

| 分类 | 类型 | 特点 |
| ---- | ---- | ---- |
| 不可变对象 | int、float、str、tuple、frozenset、bytes | 一旦创建不能修改，“修改”实际是创建新对象 |
| 可变对象 | list、dict、set、自定义类实例 | 可以原地修改，所有指向它的引用都能“看到”变化 |

不可变对象“修改”时 id 会变（其实是换了个新对象）：

```python
s = "hello"
print(id(s))       # 旧 id
s = s + " world"   # 创建了新字符串对象，s 改指向它
print(id(s))       # 新 id，和上面不同

lst = [1, 2]
print(id(lst))     # 旧 id
lst.append(3)      # 原地修改，id 不变
print(id(lst))     # 同一个对象
```

这就是为什么把可变对象作为函数默认参数是经典坑：

```python
def add_item(item, lst=[]):     # 默认参数只在函数定义时创建一次！
    lst.append(item)
    return lst

print(add_item(1))   # [1]
print(add_item(2))   # [1, 2]  ← 上次的修改还在，两次调用共享同一个 list

# 正确写法
def add_item(item, lst=None):
    if lst is None:
        lst = []
    lst.append(item)
    return lst
```

### == 和 is 的区别

- `==`：比较**值**是否相等（调用对象的 `__eq__`）
- `is`：比较**身份**是否相同（是否为同一个对象，等价于 `id(a) == id(b)`）

```python
a = [1, 2, 3]
b = [1, 2, 3]
print(a == b)   # True，值相等
print(a is b)   # False，两个不同的对象

# 例外：小整数缓存 [-5, 256] 和短字符串驻留（interning）
c = 100
d = 100
print(c is d)   # True，指向缓存的同一个 int 对象
e = 1000
f = 1000
print(e is f)   # 视运行环境而定，通常 False —— 不要依赖这个行为
```

日常判断相等用 `==`；`is` 只用于 `x is None`、`x is not None` 这类单例判断。

### 拷贝：浅拷贝与深拷贝

复制可变对象时，拷贝只复制“第一层”，嵌套的内部对象仍然共享：

```python
import copy

a = [1, [2, 3]]
b = copy.copy(a)     # 浅拷贝：外层是新的，内层 [2,3] 还是共享的
b[0] = 99
print(a)             # [1, [2, 3]]   ← 外层互不影响
b[1].append(4)
print(a)             # [1, [2, 3, 4]] ← 内层被“波及”

c = copy.deepcopy(a) # 深拷贝：递归复制所有层级，完全独立
c[1].append(5)
print(a)             # [1, [2, 3, 4]] ← 不受影响
```

```
# 浅复制
# 原先的 path 里装了一个子列表 [2, 2]
path = [[2, 2], 3]

# 浅复制！
new_path = path.copy()

# 1. 修改最外层（比如 pop 掉最后的 3）
new_path.pop()
print("原先的 path:", path)       # 输出:  [[2, 2], 3]
print("复制出的 new_path:", new_path) # 输出: [[2, 2]] 


# 2. 修改里层（比如往子列表里加东西）
new_path[0].append(99) 
print("原先的 path:", path)       # 输出: [[2, 2, 99],3] ！！！
print("复制出的 new_path:", new_path) # 输出: [[2, 2, 99]] ！！！


# 3. 修改最外层（增加100）
new_path.append(100)
print("原先的 path:", path)       # 输出: [[2, 2, 99],3] ！！！
print("复制出的 new_path:", new_path) # 输出: [[2, 2, 99],100] ！！！
```

### 传参也是传引用（严格说是“传对象引用”）

函数传参传的是引用的副本——形参和实参指向同一个对象。所以：

- 修改可变参数会影响外部（原地修改）
- 给参数重新赋值不影响外部（只是让形参改指向新对象）

```python
def modify(lst, num):
    lst.append(99)   # 原地修改 → 影响外部
    num = 100        # 重新绑定 → 不影响外部

a, n = [1], 1
modify(a, n)
print(a, n)          # [1, 99] 1
```

### await 的使用

#### await 的基本定义

1. await 只能放在 async 修饰的函数里面使用；
2. await 后面必须要跟着一个协程对象或者 Awaitable；
3. await 的目的是等待协程控制流的返回；

#### 协程的基本语法

#### 深入理解协程

1. 什么时候 await 会阻塞，什么时候不会阻塞

   - 会阻塞（挂起）：
     当 await 遇到的是异步操作，并且这个异步操作涉及 I/O 操作或者明确的耗时操作时，比如网络请求、数据库查询、文件读写、或 asyncio.sleep() 等。此时任务会挂起，事件循环可以调度其他任务。
   - 不会阻塞（不挂起）：
     当 await 操作的任务虽然耗时，但没有包含任何明确的 I/O 操作或显式的挂起机制时，任务会一直执行，直到完成为止。这时事件循环不会中断当前任务，其他任务也没有机会执行，直到当前任务完成。
   - 结论
     await 关键字的核心作用是等待一个异步任务完成，而不会阻塞事件循环，但是否会挂起任务（交出控制权）取决于 await 后面跟随的操作是否包含显式的挂起或 I/O 操作。
2. 代码实现，方便理解协程的流程

   - 代码实现 1

   ```python
   import asyncio
   import time
   # 模拟一个 I/O 操作，任务会挂起
   async def task_with_io():
       print("Task with I/O started")
       await asyncio.sleep(2)  # 模拟 I/O 操作，此时挂起，允许其他任务运行
       print("Task with I/O finished")
   # 模拟一个耗时的计算任务，任务不会挂起
   async def task_with_heavy_computation():
       print("Task with heavy computation started")
       # 模拟一个耗时的计算任务，这里没有任何 I/O 操作
       start_time = time.time()
       for _ in range(100000000):  # 假设是一个复杂的计算
           pass
       end_time = time.time()
       print(f"Task with heavy computation finished in {end_time - start_time:.2f} seconds")
   # 定义一个主函数来运行两个任务
   async def main():
       await asyncio.gather(task_with_io(), task_with_heavy_computation())
   # 运行事件循环
   asyncio.run(main())
   #  [输出结果]
   # Task with I/O started
   # Task with heavy computation started
   # Task with heavy computation finished in 2.15 seconds
   # Task with I/O finished
   ```

   - 代码实现2

   ```python
   import asyncio
   import time
   # 模拟一个 I/O 操作，任务会挂起
   async def task_with_io():
       print("Task with I/O started")
       await asyncio.sleep(2)  # 模拟 I/O 操作，此时挂起，允许其他任务运行
       print("Task with I/O finished")
   # 模拟一个耗时的计算任务，通过加入 await asyncio.sleep(0) 交出控制权
   async def task_with_heavy_computation():
       print("Task with heavy computation started")
       # 模拟一个耗时的计算任务
       start_time = time.time()
       for i in range(100000000):  # 假设是一个复杂的计算
           if i % 1000000 == 0:  # 每经过一定量的计算就交出一次控制权
               await asyncio.sleep(0)  # 主动让出控制权
       end_time = time.time()
       print(f"Task with heavy computation finished in {end_time - start_time:.2f} seconds")
   # 定义一个主函数来运行两个任务
   async def main():
       await asyncio.gather(task_with_io(), task_with_heavy_computation())
   # 运行事件循环
   asyncio.run(main())

   #【输出结果】
   # Task with I/O started
   # Task with heavy computation started
   # Task with I/O finished
   # Task with heavy computation finished in 2.10 seconds
   ```
